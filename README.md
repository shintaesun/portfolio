# 포트폴리오 로컬 작업

Python 3만 있으면 실행할 수 있습니다. 별도 패키지 설치나 빌드는 필요 없습니다.

```sh
python3 dev_server.py
```

브라우저에서 http://localhost:8000 을 엽니다. 파일을 저장하면 미리보기가 자동으로 새로고침됩니다. 종료는 실행한 터미널에서 Ctrl+C를 누릅니다.

## 수정할 파일

- `js/config.js`: 메인 문구, 소개, 프로젝트 제목·설명·영상 링크, 연락처
- `css/styles.css`: 색상, 글꼴, 간격, 반응형 디자인
- `index.html`: 페이지 구조, Tools & Skills, 페이지 제목과 메타 정보
- `js/main.js`: 프로젝트 표시, 애니메이션, 메뉴 동작

로컬 수정은 배포 사이트에 즉시 반영되지 않습니다. Vercel에 연결된 배포 브랜치에 변경 사항을 푸시하면 프로젝트의 배포 설정에 따라 반영됩니다.
